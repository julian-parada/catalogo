# Catálogo de Gorras

Página estática para mostrar gorras, seleccionar productos y enviar el pedido directamente a WhatsApp.

## Cómo agregar fotos

Pon tus imágenes dentro de `img/` y cambia las rutas/nombres en `script.js`.

Ejemplo:
`img/gorra-01.jpg`

También puedes colocar `banner.jpg` para usar una foto como fondo del encabezado.

## Número de WhatsApp

Ya está configurado:
324 734 8475

En `script.js` aparece como:
`573247348475`

## Importante

Esta versión no necesita base de datos. Los productos se editan en `script.js`.
El carrito se guarda temporalmente en el navegador.

Para una versión con panel de administración donde puedas subir fotos y productos desde la propia página, conviene agregar una base de datos y almacenamiento (por ejemplo Supabase).
